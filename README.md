# Zarden Immobilien – Website

Responsive statische Website für Zarden Immobilien in Bocholt.

## Veröffentlichen mit GitHub Pages

1. Öffne das Repository: https://github.com/Till-GH-Server/zarden-immobilien
2. Gehe auf **Settings → Pages**.
3. Wähle unter **Build and deployment** bei **Source** die Option **Deploy from a branch**.
4. Wähle Branch **main** und Ordner **/(root)**, dann speichere.
5. Warte einige Minuten. Die veröffentlichte Adresse sollte lauten: https://till-gh-server.github.io/zarden-immobilien/

## Vor produktiver Nutzung prüfen

- Impressum und Datenschutzhinweise sind Vorlagen und müssen anhand der tatsächlichen Unternehmens- und Hostingdaten geprüft und ergänzt werden.
- Die E-Mail-Adresse wurde nicht erfunden; nur die öffentlich bekannte Telefonnummer und Anschrift sind hinterlegt.
- Das Symbolbild wird von Unsplash geladen und ist kein bestätigtes Objekt von Zarden Immobilien. Lizenz und datenschutzrechtliche Einbindung prüfen; alternativ ein freigegebenes, lokal gehostetes Bild einsetzen.
- Diese statische Website versendet keine Formulardaten an einen eigenen Server. Kontakt erfolgt über den Telefon-Link oder über externe Kartensuche nach Klick.
- Dieses Repository überschreibt nicht die bestehende Website auf zarden-immobilien.de. Dafür wäre zusätzlich ein Hosting-/Domain-Schritt nötig.
